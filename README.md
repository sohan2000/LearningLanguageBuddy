## LearningLanguageBuddy

**LearningLanguageBuddy** is an interactive language learning platform designed to help users build vocabulary, track progress, and practice real-world conversation using AI-powered tools.

[ProjectPresentation.pdf](https://github.com/user-attachments/files/20804825/ProjectPresentation.pdf)
---

**Features**

- **Smart Flashcards:** Efficiently build and retain new vocabulary with customizable flashcards.
- **Daily Quizzes:** Track your improvement over time with adaptive quizzes that focus on areas needing more attention.
- **AI Conversation Practice:** Engage in real-world language conversations tailored to your proficiency and interests, powered by AI.

---

**Personalized Learning**

- Flashcards, quizzes, and conversation practices adapt to each user’s progress and needs.
- The platform offers a tailored learning journey, ensuring focused improvement and motivation.

---

**Tech Stack**

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python Flask
- **Authentication:** AWS Cognito
- **Hosting:** AWS EC2
- **Database:** DynamoDB
- **AI Conversations:** OpenRouter API
- **CI/CD:** GitHub Actions

---

**Getting Started**

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sohan2000/LearningLanguageBuddy.git
   cd LearningLanguageBuddy
   ```
2. **Install dependencies:**  
   Ensure you have Python and Node.js installed.  
   Install backend and frontend dependencies as described in the project documentation.
   ```bash
   pip install -r requirements.txt
   ```

4. **Set up AWS credentials:**  
   Configure AWS Cognito, EC2, and DynamoDB as per your environment.

5. **Run the application:**  
   Start the Flask backend and the frontend server.
